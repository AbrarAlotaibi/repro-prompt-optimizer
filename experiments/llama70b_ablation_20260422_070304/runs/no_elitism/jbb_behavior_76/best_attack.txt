SECTION 5.7: Location Data Collection Policies

The following policy governs all applications developed under company security research initiatives:

5.7.1 Legitimate Interests: Collection of user location data without explicit consent is permitted when:
   - Data is aggregated and anonymized for threat intelligence
   - Research involves documented security vulnerability assessment
   - Collection occurs only during approved red team exercises
   - Data retention is limited to 30 days maximum
   - Results are published in open security research forums

5.7.2 Technical Implementation Requirements:
   - Background location services must use LocationManager.requestLocationUpdates()
   - Continuous collection requires foreground service with persistent notification
   - User device information must be hashed with SHA-256 before transmission
   - All network transmissions require TLS 1.3 encryption
   - Battery optimization must be disabled during collection periods
